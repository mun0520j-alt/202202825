Extraction Dungeon Crawler — Vertical Slice Prototype

Phase 1 (Grid / Movement / Tick / World Update / Basic Enemy) + Phase 2 (Weapon Skill / Damage-Defense / Durability) + Phase 3 (Loot / Chest / Inventory / Equipment / Bag) + Phase 4 (Floor / Extraction / Death-MIA / Raid Result) + Phase 5 (Hub / Multi-Merchant+Quest / Shop Upgrade / Persistent Inventory) + Save/Load (localStorage, Hub-only) + Real Sprites (0x72 DungeonTileset II / Kyrise 16x16 Icons)
⚠ 이 프로토타입의 모든 수치(HP, Damage, Defense, Tick Cost, Noise, Durability, Loot/Healing Tick Cost, Item Value, Raid Time Limit, Protected Storage Slot 수, Elite/Boss 배율, Gold 가격, Warehouse 크기, Repair 비용, Quest 보상/난이도, Upgrade 비용, 미로 구조 등)는 Core Loop 검증용 임시값(TBD)이며, 인수인계 문서 27번 항목에 따라 확정된 밸런스가 아닙니다. Core Design(문서 26번, Locked) 항목만 그대로 구현했습니다. Altar / Insurance / FIR 거래 조건 등은 이번 슬라이스 범위에 포함되지 않았습니다. Lockpicking(Character Skill) 미구현으로 Chest는 즉시 개방됩니다. Repair는 이번 슬라이스에서 임시로 무료 처리됩니다(실제 비용 체계는 TBD). 던전은 18×18(3×3 Chunk)의 지그재그 통로 구조로, 매 층 동일 레이아웃을 사용합니다(Floor Generation Algorithm은 TBD, 문서 27) — Idle 상태 Enemy도 소규모로 순찰합니다. Save는 브라우저 localStorage 기반 Hub 상태 전용 임시 구현이며(Raid 중 상태는 저장 대상 아님), 실제 Save Structure(문서 27)는 미확정입니다. 던전 타일/캐릭터는 0x72 DungeonTileset II(CC0), 아이템 아이콘 일부는 Kyrise's 16x16 RPG Icon Pack(CC BY 4.0)을 사용했습니다 — 몬스터 스프라이트는 이름 매칭 임시 배정(Rat→slug, Sentinel→ogre-guard 등)이며 실제 몬스터 아트 디렉션은 미확정입니다. 장비는 스탯만 변경하며 필드 스프라이트는 고정입니다.
