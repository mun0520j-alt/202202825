# M6 테스트 케이스 — 격자 인벤토리

> 기준일: 2026-11-11. 자동 검증은 Unity `Dungeon Tools > QA > M6 Grid Model Validation`, 나머지는 통합 Play로 확인한다.

## 통합 Play 검증 체크리스트

### 준비물

- 기본 3×2 가방, Normal 4×2, Rare 3×3 가방
- 무기 1×3, 방패 2×2, 갑옷 2×3, 가방 아이템 2×2
- 상자와 바닥 더미가 있는 일반 층, 5층 보스 진입 수단
- 실행 전 `Save` 폴더 백업과 v2 `save.json` 사본

### 순서

1. **격자 기본:** TC-M6-01~07. 자동 검증 결과를 확인한 뒤 이동·회전·툴팁을 Play로 본다.
2. **루팅:** TC-M6-08~13. 상자 → 보스 → 바닥 더미 순서로 Tick과 실패 상태를 기록한다.
3. **가방·장비·영지:** TC-M6-14~18. 실패 전후 Tick, 아이템 수, 장착 상태를 함께 비교한다.
4. **모달·세이브:** TC-M6-19~22. 세이브 폴더를 백업한 뒤 v3 재실행과 v2 마이그레이션을 확인한다.
5. **측정·회귀:** TC-M6-23~24. 디버그 기능 없이 Random 5층 생환 3판 이상을 기록한다.

## 판정 메모

- `capacity_bonus`는 v2 세이브·과거 데이터 해석용으로 유지하며 M6 격자 배치에는 사용하지 않는다.
- 장비 드롭 방식 변경 전 플레이 경험과 CSV는 보존한다. M6 이후 측정은 `items_grounded_legacy`, `items_dropped_to_container`, `chest_items_generated`, `boss_items_generated`로 분리한다.
- 바닥 더미가 가득 차면 버리기 실패·이유 표시·0Tick이 현재 확정 규칙이다.
- 상자 재개봉 비용은 설정값으로 분리했으며 현재 0Tick이다. 통합 Play 후 0 또는 1Tick을 Product Owner가 확정한다.
