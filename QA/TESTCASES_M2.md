# M2 테스트 케이스 — 루팅과 손실

> 기준: `MILESTONES.md` M2 확정 규칙. 빌드: `feature/m2-loot-loss`.
> 임시값: 상자 5Tick · 층당 6~8개 · 기본 가방 6칸 · 휴식 5Tick/HP +1.
> 판정 우선순위: `Dead > MIA > Loot`, `Dead > MIA > Rest Heal`.
> 결과: Pass / Fail(BUG-ID) / Blocked(사유) / 미실행

### 빠른 검증 장치

- `F4`: 플레이어 왼쪽 실제 상자, 위 Enemy, 오른쪽 탈출구를 배치한다.
- `F5`: 원정 가방을 6/6으로 채워 가득 찬 상태의 상자·바닥 아이템 경계값을 확인한다.
- `F3`: 타일·벽·Player 검색 셀 오버레이를 표시한다.

## 7. M5 보험 백로그 기준

- 보험은 사망·MIA 확정 순간 몸에 있던 착용품과 가방 아이템만 보장하는 안을 검토한다.
- 바닥에 버린 아이템은 포기한 것으로 간주해 보험 대상에서 제외한다.
- M2에는 보험 기능을 구현하지 않는다.
