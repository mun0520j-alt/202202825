# M3 백로그 회의록 — 도감과 수집품

- 일자: 2026-11-05
- 상태: M3 후보 / 기획 필요
- Jira: [DUN-24](https://mun0520j.atlassian.net/browse/DUN-24)
- 현재 스프린트 영향: 없음 (Sprint 1·2에 추가하지 않음)

## 왜

던전 탐험에서 전투와 탈출 외에도 장기적으로 발견하고 모으는 목표를 제공한다.
사용자가 좋아했던 게임 경험을 그대로 복제하지 않고, 숫자·색·효과·설명으로 재해석한 수집품을 통해 프로젝트만의 개성과 발견의 재미를 만든다.

## 무엇

### 도감

- 획득한 수집품을 기록한다.
- 미획득 항목의 표시 방식과 해금 조건은 M3 기획에서 결정한다.
- 기본 정보 후보: 직접 제작한 그림, 이름과 설명, 획득처, 희귀도, 숨은 단서
- 일부 항목에만 특별한 사용 효과를 붙이는 방안을 검토한다.

### 아이템 드롭 테이블

- 몬스터, 상자, 기타 획득처와 수집품을 데이터로 연결한다.
- 드롭 확률, 중복 획득, 미획득 표시 규칙을 정의한다.
- 아이템과 획득처가 늘어나도 데이터 추가로 확장할 수 있는 구조를 목표로 한다.

### 수집품 방향

Escape from Tarkov의 Collector/Kappa처럼 여러 범주의 물건을 모으는 경험을 참고한다.

- 장비와 유물
- 음식
- 장난감
- 책과 기록물
- 정체불명의 잡동사니

## 오마주 원칙

- 수집품 그림은 직접 제작한다.
- 원작 캐릭터, 아이템, 로고, 원본 이미지를 그대로 사용하지 않는다.
- 일반 플레이어에게는 던전 세계관의 독립된 수집품으로 보여야 한다.
- 원작을 아는 플레이어만 숫자, 대표색, 효과, 획득 조건, 설명을 통해 알아볼 수 있게 한다.
- 단순한 외형 복제보다 좋아했던 플레이 경험과 규칙을 던전 시스템으로 번역한다.

## 아이디어 메모

### 푸른 고동북 — 마릴리 오마주 후보

핵심 단서는 외형보다 **배북 + 천하장사** 조합으로 잡는다.

- 생명력 절반을 대가로 힘을 크게 얻는 설정
- 작고 둥근 존재에게 믿기 어려운 괴력이 깃든다는 설명
- 도감 수집품으로 먼저 제작
- 실제 전투 효과 구현은 밸런스 검토 후 별도 티켓 후보

> 자신의 생명력을 절반 바쳐 북을 울린다.
> 작고 둥근 소유자에게 믿기 어려운 괴력이 깃든다고 한다.

음식형 변형 후보:

> **괴력 토끼의 반달빵**
> 절반을 떼어 먹으면 힘이 크게 오른다는 푸른 포장 간식.
> 북처럼 두드려 먹는 이상한 전통이 있다.
