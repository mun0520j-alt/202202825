## 1. 마일스톤 재배치 (확정)

메타 범위에 퀘스트·분기·인레이드가 더해져 범위가 커졌으므로 나눈다.

| 마일스톤 | 내용 |
|---|---|
| **M7 메타 경제** | 잡템, 상인 구매, 탈출 스크롤, 보험 |
| **M8 우호도·퀘스트** | 우호도, 퀘스트 체인·분기, 인레이드(Found in Raid) |
| **M9 Stash 격자** | Stash 격자·확장, 가방 = 보관함 중첩 (기존 M8에서 이동) |

이유: M7은 "Gold가 돌고 그 Gold로 리스크를 관리하는" 흐름 하나로 묶는다. 퀘스트·인레이드는 데이터 구조(퀘스트 표, 아이템 출처 표시, 세이브 v4)가 따로 커서 분리한다.

## 2. 선행 — Tick CSV 분석 (M7 착수 조건)

- M6 Random 5층 생환 3판 1,028 / 937 / 678Tick, 평균 881 → M6 회의의 재검토 조건(850 초과)에 해당.
- M7 구현 전에 **CSV 분석만** 한다. Tick 상수·행동 비용은 바꾸지 않는다.
- 분석 범위: M4 5층 생환 표본(676 / 632 / 861)과 M6 표본을 비교해 이동·전투·휴식·루팅(꺼내기·버리기)·장비 교체·상자 개봉 Tick 비중과 판당 상자 수·획득 수.
- 결과로 사용자가 판단한다: Tick 예산 유지 / 행동 비용 조정 / BETA 0.1 지인 표본까지 보류.
- 참고: M7 탈출 스크롤은 시간을 줄이는 수단이므로, 분석 결과에 따라 시간 압박 완화 장치로 쓸 수 있다.
- **분석 완료 (2026-11-12):** 격자 시스템은 원인이 아니다(루팅 +6, 장비 교체 −1). 증가분은 전투 +40·휴식 +32·이동 +81로 교전량 차이(처치 2.0→3.7, 받은 피해 59→155). Tick 1,440·행동 비용 유지, BETA 0.1 표본으로 재측정. 상세: `QA/evidence/M6/M6_TICK_ANALYSIS_2026-11-12.md`

## 3. M7 확정 결정

### 3-1. 경제 수치는 전부 임시값

- M7의 가격·보험료·반환율·대기 시간·스크롤 가격은 **임시값**이다. 경제 시스템은 M8·BETA 피드백 이후 다시 조정한다.
- 모든 수치는 CSV 또는 설정값으로 둔다(코드 하드코딩 금지).

### 3-2. 잡템

- **M7에 4~6종 추가.** 판매 전용, 크기 1×1~2×1. 상자 드롭에 섞는다.
- 목적: 격자 빈칸을 채우는 배치 판단, Gold 수입원, M8 납품 퀘스트 대상, 이후 보호 주머니 내용물.
- 이름·크기·판매가·드롭 가중치는 초안을 만들어 사용자 확인 후 확정한다.

### 3-3. 상인 구매

| 항목 | 결정 |
|---|---|
| 판매 품목 | Normal·Rare 가방, 탈출 스크롤(임시), Normal 장비 |
| 제외 | Epic·Unique 가방(5×3, 4×5)은 드롭 전용 — 격자에서 큰 가방의 가치가 크다 |
| 구매가 | 판매가 × 4 (임시) |
| 재고 | 무제한 |
| 구매품 위치 | Stash |

### 3-4. 보험 (회의 명세 그대로)

| 항목 | 결정 |
|---|---|
| 대상 | 출격 시 장착한 장비 + 가방. **가방 내용물은 보험 대상 아님.** 기본 장비 제외 |
| 보험료 | 판매가의 50%, 출격마다 지불 (임시) |
| 반환율 | 30% (임시). M8 우호도 단계당 +10%, 최대 60% |
| 대기 / 수령 유예 | 1,500Tick / 3,000Tick (던전 Tick 기준, 임시) |
| 판정 시점 | 손실 확정 즉시 판정, 결과는 대기 종료 시 공개 |
| 반환 판정 대상 | 1~7층 사망, 보험 든 장비를 던전에서 버림(생환 포함) — DUN-28 |
| 반환 불가 | MIA, 해당 원정에서 8층 이상 진입(현재 도달 불가, 코드만) |
| 제외 | 버린 뒤 같은 원정에서 다시 주운 장비 |
| 반환품 위치 | Stash |

### 3-5. 탈출 스크롤

| 항목 | 결정 |
|---|---|
| 공급 | 상인 구매 — **임시.** 퀘스트 보상·엘리트 드롭이 생기면 상점에서 회수(기획서 원래 방향) |
| 가격 | 60 Gold (임시) |
| 사용 장소 | 각 층 계단(시작) 방 |
| 체류 | 20Tick. 이탈 시 진행도 초기화 (고정 탈출구 규칙과 동일) |
| 5층 | 보스 생존 중 사용 불가 |
| 크기·소모 | 1×1, 1회용. 사망·MIA 시 손실, 생환 시 남은 스크롤은 Stash |

### 3-6. 세이브

- Gold·보험 대기 목록·수령 대기·스크롤·잡템 → `save_version` 4. v3 마이그레이션.

## 4. M8 확정 결정 (기록만, M7에서 구현하지 않음)

### 4-1. 우호도

- 퀘스트 완료로 **우호도 포인트** 획득.
- 레벨업 = **우호도 기준 + Gold 지불**: Lv2 = 우호도 100 + 300 Gold / Lv3 = 우호도 300 + 1,000 Gold.
- 레벨 효과: 단계마다 판매가 +10%, 구매가 −10%, 보험 반환율 +10%.
- 우호도 감소 없음.

### 4-2. 퀘스트

| 항목 | 결정 |
|---|---|
| 종류 | 납품("Normal 갑옷 3개"), 생환("5층 보스 처치 후 생환"), 운반("Rare 이상 2개를 들고 3층 생환") |
| 연결 | 하나 깨면 다음이 열리는 **체인** + 중간에 **분기 1회**(예: 전투 루트 / 수집 루트 중 택1, 다른 쪽 닫힘) |
| 보상 | 우호도 포인트 + Gold + 장비 등 |
| 납품 | 납품한 아이템은 소멸 |
| 데이터 | 퀘스트 CSV 표 (`quest_id`, 선행 퀘스트, 분기 그룹, 종류, 목표, 개수, 보상) |

### 4-3. 인레이드 (Found in Raid)

- 납품 퀘스트는 **인레이드 표시가 있는 아이템만** 받는다.

| 아이템 출처 | 인레이드 |
|---|---|
| 던전에서 주워 생환 | O |
| 상점 구매 | X |
| 보험 반환 | X |
| 기본 장비 | X |
| 표시 없는 아이템을 들고 출격 후 생환 | X (그대로) |
| 표시 있는 아이템을 들고 출격 후 생환 | **미결 — 추천: O 유지** |

- 판매는 표시와 무관. 격자에 아이콘으로 표시. 세이브에 아이템별 플래그.
