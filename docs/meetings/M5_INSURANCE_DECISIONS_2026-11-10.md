# M6 보험 전략 결정 회의

- 일자: 2026-11-10
- 상태: 기획 확정 / M6 구현 대기
- 현재 스프린트 영향: 없음
- 범위: 영지 보험 반환 판정과 바닥 투기 전략

## 논의 배경

보험에 가입한 장비를 던전 바닥에 버린 뒤 생환하거나 원정을 종료하는 행동이 보험 반환 대상으로 인정되는지 검토했다. 바닥에 버리는 순간 장비를 즉시 잃고, 반환 여부와 시점도 확정되지 않으므로 무비용 악용이 아니라 위험을 감수하는 선택으로 판단했다.

## 확정 결정

1. 보험 장비를 던전 바닥에 버린 경우 생환을 포함해 보험 반환 판정 대상으로 둔다.
2. 반환 여부에는 반환율을 적용한다.
3. 반환 성공 후에도 대기 시간이 존재한다.
4. 수령 기한 안에 회수하지 않으면 반환품을 잃는다.
5. MIA와 8층 이상 진입은 반환 불가다.
6. 의도하지 않은 공략이라도 선택 비용과 위험이 있고 재미를 만든다면 허용한다.

## 악용 방지 기준

- 바닥 투기는 장비를 즉시 사용할 수 없게 만드는 실제 비용을 가진다.
- 반환이 확정되지 않으며 즉시 지급되지 않는다.
- 반환율·대기 시간·수령 기한을 함께 조정해 항상 최적 행동이 되지 않게 한다.
- 구체적인 확률과 시간은 M6 구현 전에 별도 결정한다.

## M4와의 경계

- M4에서는 보험 기능을 구현하지 않는다.
- M4 보스 드롭과 기존 바닥 아이템 소멸 규칙은 그대로 유지한다.
- 이 문서는 M6 구현과 QA 결정 테이블의 원본으로 사용한다.
