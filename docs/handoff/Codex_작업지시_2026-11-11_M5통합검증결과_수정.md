## 2. 결함 수정

### 2-1. BUG-035 — 장비 슬롯 글자 가독성 (Minor, UX)

- **재현:** 던전 인벤토리 왼쪽 장비 목록.
- **실제:** 흰색 글자가 주황 막대·가로 줄 장식 위에 겹쳐 읽기 어렵다. `왕실 원정 가방 +6`처럼 긴 이름은 끝이 `해제` 버튼에 가려진다.
- **기대:** 이름·수치가 배경과 충분히 대비되고, 버튼에 가리지 않는다.
- **수정 방향:**
  - 글자 뒤 장식 줄을 제거하거나 글자 영역 밖으로 뺀다. 글자 영역은 어두운 단색 배경.
  - 글자 크기 유지, 필요하면 외곽선(Outline/Shadow)으로 대비 확보.
  - 이름 영역 폭을 `해제` 버튼 폭만큼 줄이고, 넘치면 말줄임(…) 또는 두 줄.
  - 빈 슬롯(반지·목걸이)은 회색 글자로 구분.
- 새 아트는 만들지 않는다. 기존 생성 스프라이트·색상만 조정.
- 수정 전후 스크린샷을 보고에 첨부한다.

### 2-2. BUG-036 — 자동 이동 중 Esc 처리 불명확 (Minor)

**사용자 결정 (2026-11-11):** 자동 이동 중 Esc는 **자동 이동을 취소**한다. 메뉴를 닫아도 이어가지 않는다. 자동 휴식(2-3)과 같은 규칙이다.
이유: 클릭 한 번으로 시작한 이동을 멈출 수 없으면 위험 지역으로 걸어 들어가는 "자살 버튼"이 된다. 취소 수단이 확실해야 한다.

**현재 코드 확인 (Claude, `PlayerTurnActor.cs`)**

- 이미 있는 취소 수단: 우클릭·Esc(`ClearQueuedAutoPath`, 341행 부근), 방향키 입력, 새 Enemy 시야 진입 시 정지(`visibleEnemiesAtAutoPathStart`).
- 경로 미리보기는 이미 `LineRenderer mousePathPreview` 하나를 쓰는 구조다. 사용자 제안(선 하나 재사용, 지나간 구간 지우기)과 방향이 같다.
- 문제: `PauseMenuController.BlocksWorldInput`이면 `Update` 초반에 return 한다. Esc 한 번에 메뉴가 열리는 것과 경로 취소가 **같은 프레임 실행 순서에 따라** 달라질 수 있다. Play에서 화살표가 사라진 것은 경로가 취소됐기 때문으로 보이나, 확실하지 않다.

**수정**

- 일시정지 메뉴가 **열리는 순간** 자동 이동 경로와 자동 휴식을 명시적으로 취소한다(메뉴 컨트롤러 → Player 취소 호출 또는 이벤트). 프레임 순서에 의존하지 않는다.
- 취소되면 경로 미리보기도 같이 숨긴다. 메뉴를 닫은 뒤 Player는 제자리, 추가 Tick 없음.
- 경로 진행 중에는 지나간 구간이 미리보기에서 지워지는지 확인하고, 안 되면 사용자 제안대로 앞쪽 점을 제거한다. 경로 표시 오브젝트는 계속 1개만 재사용(Destroy·재생성 금지).
- **취소 수단을 화면에 보이게 한다:** 자동 이동 중 HUD에 짧은 안내 `자동 이동 중 · 우클릭/Esc 취소` 표시. 이동이 끝나거나 취소되면 사라진다. 새 아트 없이 기존 HUD 글꼴.
- 기존 취소 규칙(우클릭·방향키·새 Enemy 발견 정지)은 바꾸지 않는다.

### 2-3. 자동 휴식 — Esc로 취소 (사용자 결정 2026-11-11)

- **결정:** 자동 휴식(Space 누르고 있기) 중 Esc를 누르면 **휴식을 끊는다.** 메뉴를 닫아도 휴식이 다시 시작되지 않는다.
- **이유:** Esc를 눌렀는데 휴식이 이어지면 결함처럼 보인다.
- `PlayerTurnActor`의 `CancelAutoRest` 경로를 사용한다. 이미 진행된 5Tick 단위 회복은 유지, 진행 중이던 단위는 지급하지 않는다(현재 취소 규칙과 동일하게). 다르면 보고한다.
- `MILESTONES.md` 결정 기록에 추가 (자동 이동 Esc 취소 결정과 함께).
