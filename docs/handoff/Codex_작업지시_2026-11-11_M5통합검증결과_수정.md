## 2. 결함 수정

### 2-1. BUG-035 — 장비 슬롯 글자 가독성 (Minor, UX)

- **재현:** 던전 인벤토리 왼쪽 장비 목록.
- **실제:** 흰색 글자가 주황 막대·가로 줄 장식 위에 겹쳐 읽기 어렵다. `왕실 원정 가방 +6`처럼 긴 이름은 끝이 `해제` 버튼에 가려진다.
- **기대:** 이름·수치가 배경과 충분히 대비되고, 버튼에 가리지 않는다.
- **수정 방향:**
  - 글자 뒤 장식 줄을 제거하거나 글자 영역 밖으로 뺀다. 글자 영역은 어두운 단색 배경.
  - 글자 크기 유지, 필요하면 외곽선(Outline/Shadow)으로 대비 확보.
  - 이름 영역 폭을 `해제` 버튼 폭만큼 줄이고, 넘치면 말줄임(…) 또는 두 줄.
  - 빈 슬롯(반지·목걸이)은 회색 글자로 구분.
- 새 아트는 만들지 않는다. 기존 생성 스프라이트·색상만 조정.
- 수정 전후 스크린샷을 보고에 첨부한다.

### 2-2. BUG-036 — 자동 이동 중 Esc 시 경로 화살표 사라짐 (Minor)

- **재현:** 멀리 클릭해 자동 이동 → 이동 중 Esc → 메뉴 → 계속.
- **실제:** 경로 화살표(경로 표시)가 사라진다.
- **사용자 제안 (설계 방향):** 경로 표시를 매번 인스턴스로 만들지 않는다. 반복되면 더미 오브젝트가 쌓인다. **경로 표시용 선 하나를 두고 재사용**한다. Player가 칸을 지날 때마다 지나간 구간을 지운다(비활성).
- **구현:**
  - 경로 표시 오브젝트 1개(예: `LineRenderer` 또는 기존 방식 중 하나)를 재사용. 새 경로면 점 목록만 교체한다.
  - Player가 한 칸 이동할 때마다 앞쪽 점을 제거한다.
  - 경로가 끝나거나 취소되면 비활성화(Destroy 아님).
  - 현재 경로 표시를 만드는 코드를 `rg`로 찾아, 반복 생성·미해제 오브젝트가 있는지 확인하고 보고한다.
- **Esc 시 동작 — 사용자 확인 필요:** 아래 2-3과 맞춰 자동 이동도 Esc로 **취소**할지(추천), 메뉴를 닫으면 이어갈지. 결정 전에는 현재 동작(이어감 또는 취소)을 유지하되, **어느 쪽이든 경로 표시는 실제 이동 상태와 일치**해야 한다.
  - 이어가면: 메뉴 닫은 뒤 남은 경로가 다시 보인다.
  - 취소하면: 경로 표시도 같이 사라진다.

### 2-3. 자동 휴식 — Esc로 취소 (사용자 결정 2026-11-11)

- **결정:** 자동 휴식(Space 누르고 있기) 중 Esc를 누르면 **휴식을 끊는다.** 메뉴를 닫아도 휴식이 다시 시작되지 않는다.
- **이유:** Esc를 눌렀는데 휴식이 이어지면 결함처럼 보인다.
- `PlayerTurnActor`의 `CancelAutoRest` 경로를 사용한다. 이미 진행된 5Tick 단위 회복은 유지, 진행 중이던 단위는 지급하지 않는다(현재 취소 규칙과 동일하게). 다르면 보고한다.
- `MILESTONES.md` 결정 기록에 추가.
