## 1. 사용자 결정 요약 (원문: 회의록 2장)

### 1-1. 인레이드
- 던전에서 획득해 생환한 아이템에 표시. 다시 들고 출격 후 생환해도 **유지**.
- 표시 없음: 상점 구매, 보험 반환, 기본 장비, 표시 없는 아이템을 들고 출격 후 생환.
- 표시: 격자 아이템 좌상단 작은 아이콘 + 툴팁 문구. 판매는 표시와 무관.
- 납품 퀘스트만 인레이드 필요. 생환·운반 퀘스트는 무관.

### 1-2. 퀘스트
- 체인 6개 = 공통 3 + 분기 루트별 3. Q3 완료 후 전투/수집 택1, 다른 루트 닫힘, 되돌리기 불가.
- 한 번에 1개 진행. **포기 기능 없음.**
- 납품품은 소멸. 보상 아이템은 Stash로(인레이드 표시 없음).
- 데이터: 퀘스트 CSV (`quest_id`, 선행, 분기 그룹, 종류, 목표, 개수, 보상).

### 1-3. 우호도
- 퀘스트 완료로 포인트. 기준 도달 시 상인 화면에 "레벨업" 버튼 → Gold 지불 확인창.
- Lv2 = 100 + 300 Gold, Lv3 = 300 + 1,000 Gold (설정값). Gold 부족 시 실패 + 이유.
- 레벨당 판매가 +10%, 구매가 −10%, 보험 반환율 +10% (설정값, 최대 Lv3).

### 1-4. 세이브 v5
- 아이템별 인레이드 플래그, 퀘스트 진행·완료·분기 선택, 우호도 포인트·레벨.
- v4 → v5 마이그레이션, `save_v4.bak` 보존(v3 때와 같은 방식).
