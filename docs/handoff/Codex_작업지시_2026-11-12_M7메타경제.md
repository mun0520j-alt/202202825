## 1. 사용자 결정 요약 (원문: 회의록)

### 1-1. 상인 구매

| 항목 | 결정 |
|---|---|
| 판매 품목 | Normal·Rare 가방, 탈출 스크롤(임시), Normal 장비(무기·방패·갑옷) |
| 제외 | Epic·Unique 가방은 드롭 전용 |
| 구매가 | 판매가 × 4 (임시, 설정값) |
| 재고 | 무제한 |
| 구매품 | Stash로 이동 |
| Gold 부족 | 구매 실패 + 이유 |

### 1-2. 탈출 스크롤

| 항목 | 결정 |
|---|---|
| 공급 | 상인 구매 (임시 — 이후 퀘스트·엘리트 드롭으로 회수) |
| 가격 | 60 Gold (임시). 판매가는 15로 두어 구매가 ×4 규칙과 맞춘다 |
| 크기 | 1×1, 1회용 |
| 사용 | **1Tick.** 사용하면 Player 위치를 중심으로 **3×3 임시 탈출구** 생성 (사용자 결정 2026-11-12) |
| 사용 장소 | **어디서나.** 단 3×3 아홉 칸이 전부 걸을 수 있는 바닥이어야 함(벽·문·계단·상자 칸 제외). 아니면 사용 실패 + 이유, 0Tick, 스크롤 유지 |
| 체류 | 임시 탈출구 안에서 **20Tick** 체류하면 생환. 구역을 벗어나면 진행도 0 (기존 3×3 탈출 구역 규칙 재사용) |
| 소멸 | 탈출구는 **생성 후 50Tick이 지나면 사라짐.** 체류를 못 채우면 스크롤은 소모된 채 실패 |
| 5층 | 보스 생존 중 사용 불가 + 이유 |
| 결과 판정 | 기존 탈출과 같은 경로. 같은 Tick 충돌 시 Dead > MIA > Escaped. 1,440 경계 규칙 동일 |
| 손실 | 사망·MIA 시 손실, 생환 시 남은 스크롤 Stash |
| 측정 | CSV에 `escape_method`(stairs·scroll) 기록 |

- 임시 탈출구 표시: 3×3 바닥 강조 + 남은 소멸 Tick과 체류 진행도를 HUD에 표시.
- 원정 중 임시 탈출구는 동시에 1개만. 이미 있으면 새 스크롤 사용 불가 + 이유.

### 1-3. 보험

| 항목 | 결정 |
|---|---|
| 가입 | 영지에서 출격 전, 장착한 장비 + 가방 단위로 선택 |
| 대상 제외 | 기본 장비, **가방 안 내용물** |
| 보험료 | 판매가의 50%, 출격마다 (임시) |
| 반환율 | 30% (임시, 설정값). M8 우호도 보너스를 더할 수 있게 구조만 둔다 |
| 반환 판정 대상 | 1~7층 사망, 보험 든 장비를 던전에서 버림(생환 포함) |
| 반환 불가 | MIA, 해당 원정 8층 이상 진입(도달 불가, 코드만), 버린 뒤 같은 원정에서 다시 주운 장비 |
| 판정 시점 | 손실 확정 즉시 판정, 결과는 숨김 |
| 반환 대기 | 1,500Tick (던전 Tick 누적, 임시) — 끝나면 결과 공개 |
| 수령 유예 | 3,000Tick (임시) — 영지에서 수령하지 않으면 소멸 |
| 반환품 | Stash |
| 영지 표시 | 반환 대기 목록(남은 Tick), 수령 가능 목록, 결과(반환/미반환) |

### 1-4. 세이브 v4

- Gold, 보험 가입 상태(출격 중), 반환 대기·수령 대기 목록(남은 Tick 포함), 스크롤, 잡템.
- v3 → v4 마이그레이션, `save_v3.bak` 보존(v2 때와 같은 방식).
