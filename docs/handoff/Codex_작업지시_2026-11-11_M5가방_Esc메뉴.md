## 1단계 · 가방 장비

### 1-1. 데이터 (`items.csv`) — 수치는 초안, 통합 Play 후 사용자 확정

| item_id | 이름 | 등급 | capacity_bonus | sell_price | drop_weight |
|---|---|---|---:|---:|---:|
| `bag_basic` → 유지 또는 `bag_normal`로 정리 | 여행용 가방 | Normal | **+2** (현재 +4에서 변경) | 10 | 50 |
| `bag_rare` | (이름 제안) | Rare | +3 | 30 | 50 |
| `bag_epic` | (이름 제안) | Epic | +4 | 80 | 50 |
| `bag_unique` | (이름 제안) | Unique | +6 | 200 | 50 |

- 칸 수·드롭 가중치는 **초안**이다. 사용자 미확정 상태임을 CHANGELOG·DATA_DICTIONARY에 적는다.
- 가중치 50 근거: 등급별 후보가 무기·방패·갑옷 각 100 + 가방 50 → 가방 확률 약 14%. 100이면 25%로 장비 드롭이 눈에 띄게 줄어든다.
- `item_id`를 바꾸면 기존 세이브(`bag_basic`)를 읽을 수 있게 매핑하거나, `bag_basic`을 그대로 Normal 가방으로 쓴다. 어느 쪽인지 보고한다.
- 이름은 제안만 하고 사용자 확인을 받는다.

### 1-2. 드롭

- `LootItemDatabase`의 드롭 후보에서 `Type != Bag` 제외 조건을 제거한다 (일반 드롭·보스 드롭 둘 다).
- 등급 확률과 드롭 개수 규칙은 바꾸지 않는다. 등급을 먼저 뽑고 그 등급 안에서 아이템을 뽑는 구조 유지.
- 드롭 분포 자동화(TC-M3-28, TC-M4-91)를 재실행한다. 등급 분포는 유지, 등급 내 아이템 분포에 가방이 가중치대로 나오는지 추가 확인.

### 1-3. 규칙

| 상황 | 동작 |
|---|---|
| 기본 상태 | 가방 장착 없음 = 기본 6칸. **무료 기본 가방은 없다** |
| 영지에서 Stash·출격 가방의 가방 아이템 장착 | 0Tick. 용량 = 6 + 보너스 |
| 영지에서 가방 교체 | 기존 가방은 Stash로. 새 용량이 현재 출격 가방 아이템 수보다 작으면 **실패 + 이유 표시** ("가방에 아이템이 N개라 교체할 수 없음") |
| 영지에서 가방 해제 | Stash로 이동. 출격 가방 아이템 수가 6을 넘으면 **실패 + 이유** |
| 던전 안 가방 교체·해제 | **불가 (현 동작 유지)**. 인벤토리에서 이유 표시 |
| 던전에서 가방 아이템 획득 | 출격 가방 칸을 차지하는 일반 전리품으로 취급 |
| 생환 | 장착 가방 유지 |
| 사망·MIA | 장착 가방 **전손** (다른 장착 장비와 동일) |
| 판매 | 다른 장비와 같은 규칙. 장착 중이면 해제 후 판매 |

- 출격 직전 손실 기준 세이브(`expedition_in_progress`)에 장착 가방도 손실 대상으로 포함되는지 확인한다.
- 기본 장비 판매 금지(`basic_` 접두사)와 충돌하지 않게 `bag_basic` ID를 확인한다. **`bag_basic`이 판매 금지에 걸리면 안 된다**(드롭 아이템이다). 접두사 비교 대신 기본 장비 판별을 명시적 필드나 목록으로 바꾸는 것을 검토하고 보고한다.
- 데이터 소유자는 `LootRuntimeState` 유지. `EquippedBagCapacityBonus` 갱신이 장착·해제·교체·세이브 로드에서 모두 일어나는지 확인한다.

### 1-4. UI

- `BaseCampManagementPanel`: 가방 아이템에도 "장착" 버튼 표시. 장착 장비 영역에 가방 슬롯과 현재 용량(예: `가방 3/10`) 표시.
- 정렬·필터에 가방 부위 추가.
- 던전 인벤토리: 가방 아이템 아이콘이 없으면 기존 생성 스프라이트 규칙으로 표시. 새 아트는 만들지 않는다.

## 2단계 · Esc 일시정지 메뉴

### 2-1. Esc 우선순위 (위에서부터 하나만 처리)

1. 설정 창이 열려 있으면 → 설정 닫기 (일시정지 메뉴로 돌아감)
2. 일시정지 메뉴가 열려 있으면 → 메뉴 닫기 (= 계속)
3. 인벤토리·Unique 판매 확인창 등 다른 UI가 열려 있으면 → 그 UI만 닫기 (기존 TC-M5-31)
4. 아무것도 없으면 → 일시정지 메뉴 열기

### 2-2. 메뉴

| 버튼 | 던전 | 영지 |
|---|---|---|
| 계속 | 메뉴 닫기 | 메뉴 닫기 |
| 설정 | 설정 창 | 설정 창 |
| 종료 | **확인창: "원정 중 종료하면 MIA 처리되어 장착품과 획득품을 모두 잃습니다."** 확인 시 종료 | 저장 후 종료 (확인창 없음) |

- 메뉴가 열려 있는 동안 이동·공격 등 Tick을 쓰는 입력은 막는다. 메뉴 자체는 0Tick.
- 종료는 `Application.Quit()`. 에디터에서는 플레이 모드 종료로 대체하고 로그를 남긴다.
- 던전 종료 시 MIA 처리 자체는 기존 세이브 구조(출격 시 손실 기준 선저장)가 담당한다. 종료 버튼에서 결과를 따로 쓰지 않는다. 다음 실행 시 기존 "MIA 처리되었습니다" 안내가 나오는지만 확인한다.

### 2-3. 설정

- 항목: 전체화면 켜기·끄기, 해상도 선택 (`Screen.resolutions` 기준, 중복 주사율 제거).
- 적용 버튼 없이 즉시 적용 또는 적용 버튼 중 하나로 구현하고 보고한다.
- 세이브 `settings`에 `fullscreen`, `resolution_width`, `resolution_height` 저장. 실행 시 저장값 적용. 저장된 해상도가 현재 모니터에 없으면 기본값으로 되돌리고 로그.
- 설정 변경은 `save_version`을 올리지 않아도 되는지 검토한다 (필드 추가만이면 2 유지 가능). 판단을 보고한다.
