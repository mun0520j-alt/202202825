# M4 작업 목록 — 4층 확장과 5층 보스

- 브랜치: `feature/m4-depth-expansion`
- 기준: `v0.3-m3` / PR #6 병합 커밋 `d32d835`
- 상태: 구현 및 사용자 Play 검증 완료, 자동 분포 검증 대기
- 목표 태그: `v0.4-m4`

## 1. 목표

M3에서 검증한 1~3층 원정 루프를 4층 일반 던전과 5층 보스까지 확장하고, 보스 처치 후 5층에서 생환하는 한 사이클을 완성한다.

## 2. 현재 확정 규칙

| 항목 | 규칙 | 근거 |
|---|---|---|
| 층 구조 | 1→5층 단방향, 이전 층 복귀 불가 | M4 확정 범위 |
| 원정 시간 | 06:00 시작, 1Tick=1분, MIA 1,440Tick | M0~M3 현재 명세 |
| 탈출구 | 3층 고정, 5층 보스 처치 후 개방 | 시스템 기획서 탈출 구조 |
| 5층 보스 | 단일 공격 + 범위 예고 공격의 2패턴 | 사용자 결정·전투 성장 회의록 |
| 보스 수치 | 현재 전투 공식의 임시 설정값. 전투·성장 공식과 분리 | M4 이후 재조정 예정 |
| 후속 범위 | 6~7층·심야·7층 폐쇄·M 키 지도 | M4 이후 |

## 3. 구현 순서

### M4-0 · 기준선과 기술 부채

- M3 핵심 회귀를 M4 시작 기준으로 고정한다.
- TD-005: F4/F5/Tick/HP 중 어떤 QA 조작으로 CSV가 제외됐는지 로그에 표시한다.
- TD-006: Fixed 모드일 때 화면에 `FIXED SEED`를 표시한다.
- M4 CSV 스키마에 필요한 컬럼을 먼저 확정하고 기존 v1~v3는 보존한다.

완료 기준:
- 일반 Random 측정과 Fixed/QA 원정을 화면·로그·CSV에서 혼동하지 않는다.
- 기존 CSV를 삭제하거나 변환하지 않는다.

### M4-1 · 4~5층 원정 확장

- `ExpeditionSession.FinalFloor`와 층 이동·결과 판정을 5층까지 확장한다.
- 층 이동 시 Seed, Tick, HP, 가방, 장비, 문·바닥 아이템의 층별 상태 규칙을 유지한다.
- 4층은 기존 9~12방 일반 생성 규칙, 5층은 28×28 단일 보스 아레나를 사용한다.

완료 기준:
- 1→2→3→4→5 진행 가능, 역행 불가.
- 3층 탈출구가 확장 이후에도 기존 규칙(3×3 구역 10Tick 체류)대로 작동한다.
- 층 이동으로 HP·Tick·원정 가방이 초기화되지 않는다.
- 같은 Run Seed가 1~5층에서 유지된다.

### M4-2 · 5층 보스 관문

- 5층은 보스 전용 층이다. 일반 Enemy와 일반 상자는 생성하지 않는다.
- 일반 층은 9~12방 절차 생성을 유지하고, 5층은 방 수를 줄이는 대신 28×28 기본값의 큰 단일 아레나로 생성한다. 크기는 설정값으로 둔다.
- 보스는 HP 기반으로 처치한다. HP 320·방어 10으로 기본 장비 피해 40 기준 8타이며 타격 횟수 강제 판정은 사용하지 않는다.
- 단일 공격은 공격력 43으로 기본 장비 Player에게 최종 피해 6을 주며 설정값으로 관리한다.
- 패턴 순서는 `단일 공격 → 단일 공격과 동시에 광역 예고 → 5Tick 뒤 광역 발동`으로 고정한다.
- 공격 5Tick과 이동 1Tick 중 어떤 선택을 할지 예고 시간이 의미 있게 설정돼야 한다.
- 보스방 안쪽의 탈출 공간은 보스 처치 직후 개방되며 5Tick 체류로 생환한다.
- 보스 생존 중에는 5층 탈출구를 사용할 수 없다.
- 같은 Tick에 보스 처치와 예약 광역 발동이 겹치면 보스 사망을 먼저 확정하고 예약 광역을 취소한다.
- 광역 공격은 방어와 무관한 최종 피해 35이며 설정값으로 관리한다.
- 보스 처치 후 5층 전체에서 같은 칸 대기 5Tick당 HP +20을 회복한다. 이 규칙은 **보스 처치 후 정비**이며 `안전지대`나 `쉼터`라는 별도 시스템으로 부르지 않는다.
- Tick 페이백과 시간 정지는 사용하지 않는다. 보스 처치 전후에도 원정 누적 시간은 연속된다.
- 보상 상자는 생성하지 않는다. 보스는 아이템만 바닥에 떨어뜨리며 줍기 1Tick, 층 이동 시 소멸 등 기존 바닥 아이템 규칙을 그대로 따른다.
- 드롭 수량은 0개 10% / 1개 70% / 2개 20%다. 각 아이템은 Rare 50% / Epic 40% / Unique 10%로 독립 판정하며 동일 아이템 중복을 허용한다.

임시값으로 분리할 항목:
- HP·공격력·방어력·층 배율
- 범위 공격 범위·피해·재사용 주기
- 보스방 크기
- 보스 드롭 확률은 설정값으로 분리해 코드 수정 없이 조정 가능하게 한다.

완료 기준:
- 보스 생존 중 5층 탈출구 차단, 처치 후 개방.
- 보스 처치 후 5층 탈출 시 생환 판정과 전리품 보존이 3층 탈출과 같은 규칙을 따른다.
- 예고 범위 밖 이동으로 회피 가능.
- 같은 Tick에 보스가 죽으면 예약 광역이 취소된다.
- 보스 처치 후 5층에서만 정비 회복량 2배가 적용되고 누적 Tick은 계속 흐른다.
- 보스 드롭은 기존 바닥 아이템 규칙으로 획득·소멸한다.
- 고정 Seed에서 수량·등급·아이템이 재현되고, 자동 분포 검증이 설정값 허용 오차 안에 들어온다.

## 4. 후속 로드맵 — M4 범위 아님

### 심야 전환

- 1,080Tick 도달 시 심야 상태를 원정 전체에 한 번 적용한다.
- 기본 원칙: Enemy 피해 증가, Player 시야 감소, 심야 전용 Enemy 풀, 위험 증가에 대응하는 보상 증가.
- 장기 설계 문서의 피해 ×1.3은 1Tick=5분 시절 수치다. 현재 Enemy 피해 2에 적용하면 2.6이고, 반올림 시 3(+50%)이 된다. 배율은 현재 전투 수치로 다시 정한다.
- 심야 전환은 현재 층을 다시 생성하지 않고 이후 생성·행동·표시에 일관되게 반영한다.
- 심야 전용 Enemy 후보 `imp`·`chort`·`big_demon`의 실제 사용 범위와 에셋 상태를 구현 전에 확인한다.

미확정 — 사용자 결정 후 구현:
- Enemy 피해 증가 배율(또는 고정 증가량)
- 시야 축소 폭
- 보상 증가 폭과 적용 대상
- 일반 Enemy를 심야 전용 Enemy로 교체하는 비율
- 소수점 피해 반올림 규칙

완료 기준:
- 1,079Tick에는 기본 상태, 1,080Tick부터 심야 상태.
- 층 이동·문·경보·보스 전투 중에도 심야 상태가 풀리지 않는다.
- 동일 Seed에서 심야 교체 결과가 재현된다.

### 7층 00:30 탈출구 폐쇄

- 7층 탈출구는 폐쇄 전까지 기존 10Tick 체류 방식으로 작동한다.
- 판정은 탈출 시작이 아니라 완료 Tick 기준이다.
- 폐쇄 뒤 탈출구는 상호작용 불가 상태와 이유를 UI로 표시한다.
- Dead > MIA > Escaped 우선순위를 유지한다.

미확정 — 사용자 결정 후 구현:
- 정확한 경계: 완료 1,109까지 생환 / 1,110부터 폐쇄인지
- 폐쇄 후 다른 탈출 수단이 없는 상태에서 MIA까지 계속 플레이 가능한지
- 탈출 체류 중 1,110에 도달하면 즉시 중단할지, 완료 판정 때 실패할지

완료 기준:
- 폐쇄 직전·정확한 폐쇄 Tick·폐쇄 다음 Tick의 경계 결과가 명세와 일치.
- Space 유지나 전투 입력으로 폐쇄·탈출 판정이 밀리지 않는다.

### M 키 지도

- 기존 작은 실시간 카메라형 미니맵을 전체 지도 UI로 교체한다.
- M 입력으로 열고 닫으며 0Tick이다.
- 방문한 Room과 확인된 문·연결을 실시간 갱신한다.
- 미방문 방, 출구, 상자, 비밀방은 기본 지도에서 자동 공개하지 않는다.
- 지도 UI가 열려 있을 때 이동·전투 입력 처리 규칙을 명확히 한다.

후속 범위:
- 상인이 판매하는 지도 등급별 출구·상자·비밀방 표시.
- Seed 복사·공유를 이용한 Sandbox 모드.

완료 기준:
- 현재 층 방문 정보가 실시간 반영되고 층별 정보가 섞이지 않는다.
- 열기·닫기에 Tick이 들지 않는다.
- 지도 UI가 게임 입력을 중복 처리하지 않는다.

### 후속 측정과 자동화

- 후속 층 확장 시 자동화 범위도 함께 확장한다.
- 원정 CSV 신규 버전 후보 필드:
  - `deepest_floor`
  - `boss_encounter_tick`, `boss_kill_tick`, `boss_result`
  - `midnight_reached`, `midnight_tick`
  - `floor7_enter_tick`, `exit_closed`, `exit_result`
  - 층별 이동·전투·루팅 Tick
- 지도 개방 자체는 0Tick이므로 행동 Tick 합계에 포함하지 않는다.
- 1~7층 완주 Tick 분포와 00:30 도달 가능성을 별도 측정한다.

완료 기준:
- 자동화 생성 실패 0.
- 수동 원정 로그 합계와 CSV 총 Tick 일치.
- Fixed Seed에서 보스방·심야 배치·7층 출구가 재현된다.

## 7. 명시적 제외

- 제단지기 NPC, 월식의 파편 퀘스트, 월식의 제단 해금
- 전투·성장 등급 곡선, 방어 관통, 강제 전투 보상 재설계
- 상인 시스템과 유료 지도 등급
- 보험, 보호 주머니, 탈출 스크롤
- 6층 이후 별도 대형 맵 규격
- 공개 빌드 텔레메트리
- 6~7층, 심야, 7층 탈출구 폐쇄, M 키 지도

위 항목은 M4 기능을 만들기 위해 필요한 최소 인터페이스만 고려하고 구현하지 않는다.
