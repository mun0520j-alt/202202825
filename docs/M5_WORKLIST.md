# M5 작업 목록 — 세이브·영지 기초·itch 공개

> 상태: 범위 B 확정. 세이브 핵심 구현 완료, 영지 기초 구현 대상(2026-11-11)
> 버전 목표: `v0.5`
> 기준: M4 완료 커밋 `938f155`, `docs/handoff/Codex_작업지시_2026-11-10_itch공개빌드.md`

## 1. 목표

M5는 itch 정식 공개 버전이다. 영구 세이브와 영지 장비 관리·판매·골드·Stash 정리를 연결해 다음 출격을 준비할 수 있게 하고, 공개 빌드의 입력·디버그·문서 상태를 정리한다.

## 2. 필수 범위

| 우선순위 | 항목 | 완료 기준 |
|---|---|---|
| 필수 | 영구 세이브(TD-002) | 저장·로드·백업·버전 마이그레이션과 손실 흐름 검증 |
| 필수 | 영지 장비 관리 | Stash·출격 가방·장착 장비를 BaseCamp에서 0Tick으로 이동·교체 |
| 필수 | 공용 상인·판매·골드 | 기본 장비 제외 판매, 등급별 가격, 골드 적립과 세이브 v2 |
| 필수 | Stash 정렬·필터 | 등급·부위·획득 순 정렬과 부위·등급 필터 |
| 필수 | itch 공개 빌드 정리 | 공개용 브랜치, 디버그 비활성화, Esc 인벤토리 닫기, 라이선스·조작법·알려진 문제 정리 |
| 필수 | 0.4 지인 피드백 반영 | 피드백을 Jira 백로그로 등록하고 승인된 항목만 구현 |
| 다음 | 기술 부채 정리 | TD-005·006 상태 확인, TD-008 회복량 설정값화 검토 |

## 3. 범위 제외

- 보험, 보호 주머니, 탈출 스크롤, 골드 사용처, 상인 우호도: M6 이후.
- 6~7층, 심야, 7층 폐쇄, M 키 지도.
- 등급 배율 곡선, 방어 관통, 기습 등 전투·성장 백로그.
- 공개 빌드 텔레메트리.

## 4. 세이브 결정 — 사용자 확정(2026-11-11)

| # | 결정 항목 | 확정안 | 영향 |
|---|---|---|---|
| 1 | 저장 대상 | Stash, 장착 장비, 설정(음량 등) | 원정 성과와 사용자 환경 유지 |
| 2 | 저장 시점 | 원정 결과 확정 직후, BaseCamp에서 Stash·장비 변경 시 | 결과 확정과 저장 시점을 일치시켜 중복·손실 방지 |
| 3 | 원정 중 게임 종료 | MIA 처리 및 전손 | 강제 종료로 사망·손실을 회피하는 행동 방지. itch 페이지 명시 필요 |
| 4 | 슬롯 | 1개 | MVP 복잡도 억제 |
| 5 | 데이터 버전 | `save_version` 필수, 구버전 읽기 경로 제공 | 가역적 마이그레이션과 호환성 확보 |
| 6 | 손상 대비 | 임시 파일 기록 후 교체, 직전 백업 1개 복구 | 쓰기 실패와 파일 파손 시 사용자 데이터 보호 |

현재 설정 기능은 없으므로 `settings`는 빈 객체로 저장해 구조만 유지한다. 생환 직후 Stash 정리 전의 획득품이 사라지지 않도록 BaseCamp 대기 가방도 저장하며, 출격 시 만드는 전손 기준 파일에서는 제외한다.

## 5. 구현 원칙

- 런타임 Stash와 장비 데이터 소유자를 먼저 확인하고 세이브 저장소와 UI 책임을 분리한다.
- 저장은 원자적 교체 방식으로 처리하고 성공·실패·복구를 로그로 남긴다.
- 같은 원정 결과가 두 번 반영되지 않도록 원정 식별자 또는 결과 반영 상태를 저장한다.
- `save_version = 1`부터 시작한다. 지원하지 않는 버전은 현재 파일을 덮어쓰지 않고 백업을 시도한 뒤 안전한 새 게임으로 시작한다. 실제 마이그레이션은 두 번째 버전이 생길 때 추가한다.
- 공개 빌드에서는 F4~F7 및 QA 메뉴가 동작하지 않아야 한다.

## 6. 영지 기초

- 데이터 소유자는 기존 `LootRuntimeState`를 유지하고 UI는 표시·입력만 담당한다. 새 Singleton은 추가하지 않는다.
- Stash 또는 대기 가방 장비를 0Tick으로 장착한다. 교체된 전리품 장비는 Stash로 이동하고 무료 기본 장비는 사라진다.
- 장착 장비 해제는 Stash로 이동한다. 빈 부위는 다음 출격 때만 무료 기본 장비로 채운다.
- Stash와 6칸 출격 가방 사이를 양방향 이동한다. 용량 초과는 이유를 표시하고 상태를 바꾸지 않는다.
- 장착·해제·꺼내기·넣기·판매 직후 저장한다.
- 공용 상인 1명이 Stash와 대기 가방 장비를 판매한다. 장착 중 장비와 무료 기본 장비는 직접 판매하지 못한다.
- 판매가 초안은 Normal 10 / Rare 30 / Epic 80 / Unique 200이다. Legendary는 현재 생성하지 않는다.
- Stash는 무한이며 등급·부위·획득 순 정렬과 부위·등급 필터만 제공한다.
- `save_version`을 2로 올리고 v1은 골드 0으로 읽는다.
- 등급별 가방은 기본 6칸에 +2/+3/+4/+6칸을 제공하며, 원정 중 교체·해제는 2Tick을 쓴다.
- 새 용량을 초과하면 사유를 표시하고 0Tick으로 실패한다. 자동으로 아이템을 버리지 않는다.

## 7. itch 공개 빌드

`docs/handoff/Codex_작업지시_2026-11-10_itch공개빌드.md`를 실행 기준으로 사용한다.

- M4 태그 이후 공개용 브랜치에서 작업한다.
- Esc는 인벤토리가 열려 있으면 먼저 닫고, 닫혀 있을 때만 일시정지·종료 흐름으로 이동한다.
- 일시정지 메뉴는 계속·설정·종료를 제공하고, 전체화면·해상도를 세이브 `settings`에 저장한다.
- 라이선스, 조작법, 세이브 위치, 원정 중 종료 시 MIA 규칙, 알려진 문제를 itch 페이지에 명시한다.
- 0.4 비밀 링크 피드백은 원문을 보존하고 Jira에 등록한다. 현재 스프린트 편입은 Product Owner가 결정한다.

## 8. 측정

- M4 정상 5층 생환 3판은 676·632·861Tick, 평균 723Tick으로 목표 600~850 안이다.
- 사망 2판은 2층 211Tick과 1층 89Tick이며 받은 피해 100에 의한 전투 사망이다.
- 표본 5판만으로 난이도·생환율을 확정하지 않는다. 0.4 지인 플레이 표본과 함께 5층 생환 Tick·생환율을 재평가한다.
- 공개 빌드 텔레메트리는 수집하지 않는다. 사용자가 제공한 CSV와 피드백만 사용한다.
